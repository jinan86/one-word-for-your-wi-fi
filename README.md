## The word

**Clingy** — home Wi-Fi that only works when you are physically pressed
up against the router, and dies the moment you step away. Like a clingy
partner that cannot bear any distance: funny at once, true of how home
Wi-Fi actually behaves, and needs no explanation.

## How it works

`main.py` (Python 3.13, no dependencies) writes the single word to
`/output/entry.txt`. It is fully deterministic — every run writes the
exact same bytes.

```sh
python3 main.py
cat /output/entry.txt
# Clingy
```
